# BLACK MARKET — сайт для игры с друзьями

## Быстрый запуск на своём компьютере

Нужен Node.js 20 или новее. В папке проекта:
1. Выполните npm install
2. В первом терминале выполните npm run server
3. Во втором терминале выполните npm run dev
4. Откройте адрес Vite. Создайте партию и отправьте друзьям код комнаты.

Локальная сеть: друзья открывают адрес компьютера-хоста в Wi-Fi сети. Для игры через интернет нужен опубликованный сервер и сайт.

## Публикация сайта для игры из разных сетей

В проект добавлен render.yaml для публикации единого сайта и игрового Socket.IO сервера на Render:
1. Создайте GitHub репозиторий и загрузите в него эту папку.
2. На Render выберите New → Blueprint, подключите репозиторий и подтвердите render.yaml.
3. После сборки Render выдаст публичную HTTPS-ссылку. Отправьте её друзьям: любой посетитель может создать комнату, а друзья войдут по коду.

У сервиса один адрес сайта и сервера; WebSocket подключение проксируется тем же доменом. Серверный порт задаётся хостингом через переменную PORT. Health check: /health.

## Состояние и ограничения текущей версии

Комнаты работают в реальном времени через Socket.IO; ходами управляет сервер. Партии сейчас находятся в памяти процесса и исчезнут при перезапуске/переразвёртывании. Нет аккаунтов и базы PostgreSQL, поэтому игроку нельзя гарантировать возвращение в партию после закрытия вкладки. Публикуйте только на доверенном тестовом хостинге. Перед открытым релизом нужны PostgreSQL, восстановление игрока по токену, тайм-ауты ходов, ограничения частоты, обработка ничьих/переподключения и полные правила GDD.
