# Монополия — город твоих правил

Браузерная пошаговая настольная игра для 2–4 друзей. Один игрок создаёт комнату, остальные входят по коду. Игровая доска и состояние партии синхронизируются через Socket.IO; проверка ходов и денег выполняется сервером.

## Как запустить

Нужен Node.js 20 или новее.

```sh
npm install
npm run server
```

В другом терминале:

```sh
npm run dev
```

Откройте адрес Vite, создайте комнату и передайте код друзьям. На сетевом сервере клиент и Socket.IO обслуживаются одним доменом.

## Правила прототипа

- Игроки начинают с ₽1500 и одной фишкой на старте. Комната рассчитана на 2–4 участников.
- Каждый бросает два кубика. За проход через «Старт» начисляется ₽200.
- Свободная улица доступна для покупки. Отказ начинает последовательный аукцион среди всех игроков, включая остановившегося.
- Владелец получает аренду; полный цветовой набор удваивает базовую аренду. Станции и коммунальные службы используют число принадлежащих объектов.
- Владельцы полного цветового набора строят дома за ₽100, равномерно до четырёх; пятый уровень превращается в отель. Продажа банку приносит половину цены улицы.
- Дубль даёт дополнительный бросок; три дубля подряд отправляют в участок. Выйти можно за ₽50 или пропустить ходы. Участки, налоги и карты событий влияют на деньги и позицию.
- Цель — остаться последним платёжеспособным игроком.

Числа аренды и несколько карт событий — прототипный баланс, который нужно уточнить по плейтестам. Обмены между игроками, залог, полная колода классических карт и сохранение партий в базе ещё не реализованы.

## Визуальные материалы

Улицы, фишки, карточки поля и декоративная городская иллюстрация находятся в `src/main.tsx`, `src/style.css` и `public/images/monopoly-city.svg`. Фишку можно выбрать на стартовом экране; выбор сохраняется в браузере.

## Публикация

`render.yaml` описывает один Node.js web-service, который собирает Vite и запускает Socket.IO-сервер. Комнаты хранятся в памяти процесса и очищаются при перезапуске. Бесплатный сервис может засыпать после простоя; первый запрос тогда занимает дольше.
